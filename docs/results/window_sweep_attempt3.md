# Feature-window sweep (grouped CV by run)

Generated by `python models/train_models.py --sweep 10 20 30`. The window length was chosen by out-of-fold macro-F1 of the known-class classifier. Longer windows blur the onset of a fault (see `scripts/debug_windows.py`), but the evaluated windows differ per row because a fault window must lie fully after injection, so compare with that in mind.

- environment: Python 3.14.7, numpy 2.5.4, pandas 3.0.6, scikit-learn 1.9.1, scipy 1.18.1
- hardware: AMD64 Family 25 Model 68 Stepping 1, AuthenticAMD, 16 logical CPUs, 16.8 GB RAM, Windows-11-10.0.26300-SP0
- seeds: fold split seeds 0 (main CV) and 1 (nested threshold CV); model seeds 0..4 by fold index; run seeds 1000-1707
