## Verdict

- No variant improves on the current model with a 95% confidence interval above zero. The current model is kept.
- Highest mean macro-F1: sysnorm+dropid / hgb (0.630); this is a point estimate, and its interval overlaps the current model's, so it is not evidence of an improvement.
