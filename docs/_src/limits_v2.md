- **LLM report layer, what was actually tested (2026-10-19, `docs/results/llm_live.md`, `tests/test_llm_isolation.py`).** The report text is produced off the recovery path: the deterministic template report and the runbook are fixed and proposed before the LLM thread starts, the thread holds no engine lock while it waits, nothing on the decision or action path (policy, executor, verification, ranking, classification) references the LLM module, the LLM output must validate against a strict schema and an allowed-candidate runbook, and a disagreeing answer is recorded and overridden by the engine; 12 isolation tests pass against the system code. The per-request timeout is 20 s per provider (a per-phase httpx timeout, not a total wall-clock bound; it is harmless to recovery because the call is in a background thread, but it is not a strict ceiling on report latency). **Live Gemini, five incidents with the pinned default model (`gemini-3.8-flash`): {{llm_a_valid}} answered with a schema-valid report; {{llm_a_timeouts}} timed out at 20 s and {{llm_a_other_fail}} failed with an HTTP error, so the template report was used each time and recovery was unaffected** (a direct probe showed that model answering in 8 to 77 s or not at all within 100 s, because it spends its time on internal reasoning). **Five more incidents with the faster `gemini-3.5-flash-lite`, set through the existing `GEMINI_MODEL` variable (a config override, no code change): {{llm_b_valid}} answered with a schema-valid report in {{llm_b_lat_ok}} s; the other fell back to the template after a connection error.** In both sets all incidents recovered ({{llm_a_rec}} and {{llm_b_rec}}), with the same runbooks as the evaluated runs and times to verified recovery of {{llm_a_ttvr}} s (set A) and {{llm_b_ttvr}} s (set B), within the range of the evaluated rows for the same scenarios. In set B the model's runbook suggestion equalled the deterministic runbook in every answered case; five samples are not proof of decision independence, which rests on the code-path analysis and the tests. These ten incidents are outside the frozen v2 evaluation. **Groq is untested** (no key).
