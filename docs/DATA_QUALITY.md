## Caveat on window-defined features

Features such as `err_base`/`err_fault`/`err_delta` are computed against the *known* injection window. A live system has no such window, so the shared rolling-window code (not these columns) defines the runtime feature set. These columns are usable only for the harmonised ratio/z-score subset that can be recomputed on a rolling basis.
